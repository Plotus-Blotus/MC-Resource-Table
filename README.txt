MC Resource Table 13.2 — Studio improvements

Changes from 13.1:
- Line and Rectangle outline tools, with drag preview and undo checkpoint.
- Fixed editor zoom: Zoom +/- and mouse wheel now actually change pixel scale.
- Fit button restores automatic fitting.
- Installer Inno Setup version directive fixed (previous 13.0 source had an unterminated quote).
- Smooth 3D drag rendering and resizable workspace from 13.1 retained.

Windows build:
1. Install Python 3 (with Python launcher) and Inno Setup 6.
2. Extract all files.
3. Run build_installer.bat.
4. Find MC_Resource_Table_Setup.exe in output folder.

Limitations: Windows installer and real Minecraft compatibility not tested in this Linux environment.
