MC Resource Table 13.2 - GitHub 자동 Setup.exe 만들기

1. 이 ZIP 압축을 풉니다.
2. GitHub 저장소 https://github.com/Plotus-Blotus/MC-Resource-Table 를 엽니다.
3. Add file -> Upload files에서 app.py, installer.iss, requirements.txt,
   mc_resource_table.ico, mc_resource_table.png 등 프로젝트 파일을 올립니다.
   기존 파일과 이름이 같으면 변경 사항을 확인하고 업로드하세요.
4. .github/workflows/windows-setup.yml 파일은 반드시 해당 경로로 올려야 합니다.
   GitHub 웹사이트에서 Add file -> Create new file을 선택하고,
   파일 이름에 .github/workflows/windows-setup.yml 을 입력한 후,
   이 ZIP 안의 같은 파일 내용을 복사해서 붙여넣고 Commit changes 합니다.
5. GitHub 저장소의 Actions 탭 -> Build Windows Setup.exe -> Run workflow -> Run workflow.
6. 완료 후 실행 기록의 Artifacts 섹션에서 MC-Resource-Table-13.2-Setup 다운로드.
   다운로드한 artifact ZIP 안에 MC_Resource_Table_Setup.exe가 있습니다.
7. 완성된 exe를 GitHub Releases에서 ZIP 없이 직접 받고 싶다면,
   저장소의 Releases -> Draft a new release -> Choose a tag에서 v13.2 태그를 새로 만들고
   Publish release를 누르세요. 태그 푸시로 workflow가 실행되며 성공하면 exe가 Release에 첨부됩니다.
   (직접 만든 Release와 충돌할 수 있으므로, 권장 방식은 GitHub Actions에서 태그를 push하는 것입니다.)

주의: GitHub Actions 빌드가 실제 성공하는지는 GitHub Windows runner에서 확인해야 합니다.
